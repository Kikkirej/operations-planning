# Data Model: Zero Trust PKI & Secrets Management

## Entities

### Platform CA

The root certificate authority for the local development environment.

| Field | Value |
|-------|-------|
| File (cert) | `infrastructure/certs/trust/local-ca.crt` |
| File (key) | `infrastructure/certs/trust/local-ca.key` *(never committed)* |
| Format | X.509 PEM |
| Subject | `CN=ops.local Dev CA, O=ops.local` |
| Validity | 10 years (dev) / from real CA (prod) |
| Key size | 4096-bit RSA |
| Git status | `local-ca.crt` **committed** — `local-ca.key` **gitignored** |
| Purpose | Imported into JVM truststore at image build time; installed in browser once |

### Server Certificate

Wildcard TLS certificate served by Traefik for all `*.ops.local` hostnames.

| Field | Value |
|-------|-------|
| File (cert) | `infrastructure/certs/server/local.crt` |
| File (key) | `infrastructure/certs/server/local.key` *(never committed)* |
| Format | X.509 PEM |
| Subject | `CN=*.ops.local` |
| SANs | `DNS:ops.local`, `DNS:*.ops.local` |
| Signed by | Platform CA |
| Validity | 2 years (dev) |
| Key size | 2048-bit RSA |
| Git status | Both **gitignored** — generated by `setup.sh` locally |
| Purpose | Presented by Traefik for all HTTPS connections |

### Environment Secrets

Each secret is a named environment variable consumed via `.env` (Docker Compose) or Kubernetes Secrets (AKS). All secrets are declared in `.env.example` with `CHANGE_ME_BEFORE_USE` placeholder.

| Variable | Service | Purpose | Required |
|----------|---------|---------|----------|
| `KEYCLOAK_ADMIN` | Keycloak | Admin console username | Yes |
| `KEYCLOAK_ADMIN_PASSWORD` | Keycloak | Admin console password | Yes |
| `KC_DB_USERNAME` | Keycloak | Keycloak PostgreSQL username | Yes |
| `KC_DB_PASSWORD` | Keycloak | Keycloak PostgreSQL password | Yes |
| `POSTGRES_DB` | Keycloak | Keycloak database name | Yes |
| `POSTGRES_USER` | Keycloak | Keycloak PostgreSQL superuser | Yes |
| `POSTGRES_PASSWORD` | Keycloak | Keycloak PostgreSQL superuser password | Yes |
| `CONFIG_SERVER_USERNAME` | Config Server | Basic auth username for config clients | Yes |
| `CONFIG_SERVER_PASSWORD` | Config Server | Basic auth password for config clients | Yes |
| `CONFIG_REPO_PATH` | Config Server | Host path to config file repository | Yes |
| `KEYCLOAK_URL` | Spring Boot Admin | Keycloak base URL (internal + public) | Yes |
| `KEYCLOAK_SBA_CLIENT_SECRET` | Spring Boot Admin | OAuth2 client secret for SBA | Yes |
| `APP_POSTGRES_DB` | App services | Application database name | Yes |
| `APP_POSTGRES_USER` | App services | Application database username | Yes |
| `APP_POSTGRES_PASSWORD` | App services | Application database password | Yes |
| `NEO4J_PASSWORD` | Neo4j | Graph database password | Yes |

### gitignore Rules

Central `infrastructure/certs/.gitignore`:

```gitignore
# Never commit private keys
*.key
# Never commit CA serial file
*.srl
# Never commit server-side certs (generated locally)
server/
# Allow CA public cert
!trust/local-ca.crt
```

## Directory Layout

```
infrastructure/
└── certs/
    ├── .gitignore               ← root ignore: *.key, server/, !trust/local-ca.crt
    ├── trust/
    │   ├── .gitignore           ← ignore *.key only
    │   └── local-ca.crt         ← COMMITTED: Platform CA public cert
    └── server/
        ├── .gitignore           ← ignore everything
        ├── local.crt            ← generated by setup.sh (gitignored)
        └── local.key            ← generated by setup.sh (gitignored)
```

## State Transitions

### Certificate Lifecycle

```
[ Not generated ]
      │
      ▼ setup.sh (first run)
[ Generated locally ] ─── expires ──► [ Regenerate: setup.sh --renew ]
      │
      ▼ docker build
[ Embedded in image (CA only) ]
      │
      ▼ Traefik reload
[ Active: serving HTTPS for *.ops.local ]
```

### Secret Lifecycle

```
[ .env.example (placeholder) ]
      │
      ▼ setup.sh (copy + prompt)
[ .env (placeholder values) ]
      │
      ▼ developer fills values
[ .env (real values) ]
      │
      ▼ setup.sh --check
[ Validated: no CHANGE_ME values remain ]
```
